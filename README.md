Entry for the [make.fun bounty "The Vacuum's Alibi"](https://make.fun/c/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7): the funniest one-line excuse a robot vacuum can give for missing a spot, 200 characters or fewer.

## The line

> My sensors logged the crumb at 09:41, my schedule logged it as 'someone else's job', and my battery agreed.

## How it works

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when the grader sets it). Run it with:

```sh
node main.ts
```
